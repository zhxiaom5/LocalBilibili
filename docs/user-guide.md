# 用户指南

## 启动与登录

按根目录 README 的“最小运行”步骤启动服务，然后访问 `http://localhost:8080`。首次启动会读取 `LOCALBILIBILI_BOOTSTRAP_USERNAME` 和 `LOCALBILIBILI_BOOTSTRAP_PASSWORD` 创建本地数据库与超级管理员；两项缺失时服务会拒绝创建新库。请立即在用户管理中修改密码，并为日常使用创建普通用户。

## 添加本地作品

在设置中添加媒体根目录，再从目录管理触发扫描。每位 UP 主应使用独立目录；新增作品建议遵循项目 `AGENTS.md` 的平铺存储契约。扫描后可从首页播放视频、浏览图文、按 UP 主查看和使用收藏夹。

## 下载与 Cookie

在线更新依赖可执行的 `yt-dlp`。Bilibili Cookie 是可选的私有配置：仅通过受保护的更新管理页面保存，不要复制到环境文件、截图、日志或 Git。没有 Cookie 时，公开内容和本地扫描仍可使用；受限制内容应显示明确失败信息。

## 数据备份

停止服务后备份 SQLite 数据库和媒体根目录。恢复时使用相同版本或完成数据库迁移后的版本启动，且确认进程对目标目录有读写权限。
